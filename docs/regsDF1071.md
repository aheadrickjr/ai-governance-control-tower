# DF1071 / CFPB Section 1071 Regulatory Source Reference

This project uses CFPB Section 1071 / DF1071 regulatory materials as a domain anchor for the AI Governance Control Tower sprint.

The full PDF regulatory source is intentionally not stored in this GitHub repository because the source file exceeds GitHub's 100 MB file limit.

## Purpose in This Project

The DF1071 / CFPB Section 1071 materials support the small business lending governance use case, including:

- Regulatory data collection requirements
- Small business lending reporting considerations
- Data quality and completeness expectations
- Applicant and business demographic data governance
- Auditability and control mapping
- AI governance intake and review scenarios

## Repository Usage

This repo will use summarized, project-facing artifacts derived from the regulatory source material instead of storing the full large PDF directly.
